# Favela Walking Tour - Rocinha

Website oficial para o **Favela Walking Tour**, passeios guiados na Rocinha, Rio de Janeiro.

## 🚀 Sobre o Projeto
Landing page moderna, responsiva e otimizada para conversão de reservas diretas e contato via WhatsApp com guias locais da Rocinha.

- **Stack**: HTML5, CSS3 moderno, Vanilla JavaScript.
- **Destaques**: Suporte multilíngue, galeria de imagens, integração com WhatsApp e sistema de reservas.

## 📦 Estrutura
- `index.html`: Página principal contendo toda a estrutura, estilos e scripts.
- `assets/`: Imagens e mídias visuais dos passeios.
- `DESIGN.md`: Documentação e diretrizes de design.
- `PRODUCT.md`: Especificações do produto e regras de negócio.
